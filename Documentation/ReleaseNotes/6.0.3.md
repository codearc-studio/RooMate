# RooMate 6.0.3

This patch makes RooMate clearer and smoother to use throughout the school day.

- Uses simpler, friendlier wording across the app, especially when something cannot load.
- Keeps the sidebar's Now / Up Next card out of Schedule, where the same information is already shown.
- Makes saved-data and offline messages easier to understand without hiding useful information.
- Keeps Sports focused on games and game reminders while team pages are temporarily unavailable.
- Improves the wording in Search, What's New, feedback, onboarding, settings, and several empty states.
- Fixes RooMate's public update feed so future updates can be delivered reliably.

RooMate 6.0.3 requires macOS 14 or later and supports Apple silicon and Intel Macs.
