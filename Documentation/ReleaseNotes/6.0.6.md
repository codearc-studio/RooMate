# RooMate 6.0.6

This update brings RooMate in line with the school’s new Level rotation.

- Updates the Level order for every weekday using the school’s published schedule.
- Keeps the existing bell times and non-Level blocks unchanged.
- Carries each student’s saved class details with its Level automatically.
- Updates Today, Schedule, Semester Planner, the menu bar, reminders, and other schedule-aware features from the same central schedule.
- Adds regression coverage for the complete Monday–Friday block order.

RooMate 6.0.6 requires macOS 14 or later and supports Apple silicon and Intel Macs.
